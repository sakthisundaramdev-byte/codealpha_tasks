# Docker Web Server Project

## Project Description
This project is a multi-page website deployed using Docker and Nginx.

## Features
- Multi-page website
- Responsive design
- Docker container deployment
- Nginx web server

## Technologies Used
- HTML
- CSS
- Docker
- Nginx

## Docker Commands

### Build Image
docker build -t sakthi-webserver .

### Run Container
docker run -d -p 8080:80 sakthi-webserver
